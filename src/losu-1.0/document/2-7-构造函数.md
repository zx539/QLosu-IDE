# 7- 构造函数语法糖

+ 洛书支持构造函数语法，通过内核函数 new 创建对象

```python
Student = {}
def Student.class(name,age):
    # 构造函数，显示声明，默认传递 this 指针，等同于 Student.class = def(this,name,age): ... ;
    return {
        name = name,
        age = age,
        sayhello = Student.sayhello,
    }
;
def Student.sayhello():
    print("Hello,I'm ",this.name,",",this.age)
;

s = new(Student,'ccc',18) # 语法糖，如果被调用对象是一个unit,自动尝试调用 .class 成员，传递this指针指向 Student
s.sayhello()
```
