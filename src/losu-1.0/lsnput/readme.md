# lsnput脚本层文档

本模块提供了监听、操作键盘和鼠标的功能。目前仅实现Windows平台下鼠标的监听和操作。计划在2.0.0.1版本发布Windows平台下键盘的监听和操作功能。

模块通过构造对象来组织代码。

## 获取鼠标位置

该函数的返回值是一个单元,x轴值储存在x成员中,y轴值储存在y成员中.

下面是例程

```c
引("lsnput")

令 鼠标 = 键鼠事件.鼠标()
位置 = 鼠标.位置()

打印(位置.x)
打印(位置.y)

```

## 更改鼠标位置

下面是例程

```c
引('lsnput')

令 鼠标 = 键鼠事件.鼠标()

鼠标.设置(0, 0) #鼠标会被设置到0, 0处
```

## 控制鼠标点击

下面是例程

```c
引("lsnput")

令 鼠标 = 键鼠事件.鼠标()

鼠标.点击('left') #会点击一下左键
"""
点击这个函数有两个参数,第一个是按键的字符串,默认是left.其他可能值有right、mid
第二个是点击的次数
"""

```
