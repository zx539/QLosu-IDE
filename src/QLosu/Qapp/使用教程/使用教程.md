# 洛书在线编程平台 · 使用教程

在线网址：**http://43.143.217.79或www.qlosu.online(如果域名进不去请换公网ip进入，域名可能正在进行公安备案)**
一个基于 code-server（网页版 VS Code）的在线编程环境，内置洛书（Losu）量子语言、Python 等。
打开浏览器即可使用，无需安装任何软件。

---

## 一、登录

打开网址后会看到登录页，有两种进入方式：

### 方式一：用户登录（推荐）

适合需要**保存自己代码**的人。

1. 点击「**用户登录**」标签。
2. 输入用户名和密码：
   - 用户名：2–32 位，只能用小写字母、数字、下划线 `_`、连字符 `-`。
   - 密码：至少 4 位。
3. 点击「**登录 / 注册**」。

> 💡 **无需提前注册**：第一次输入用户名时会自动帮你创建账号，并分配一个**专属文件夹**。
> 以后用同样的用户名和密码登录，就能回到你自己的文件。
>
> ⚠️ 请记住自己的密码，密码无法找回。

### 方式二：游客体验

适合**只想试一试、不需要保存**的人。

1. 点击「**游客体验**」标签。
2. 点击「**以游客身份进入**」。

> ⚠️ **游客模式下所有文件不会保存**，退出后即清空。重要代码请用用户登录。

## 二、界面简介

登录后进入网页版 VS Code，主要区域：

- **左侧**：文件资源管理器，能看到你的工作区文件。
  - 其中有一个 `losu-lpk-src` 文件夹，是**洛书示例代码库**（只读，可查看/运行，不可修改）。
- **中间**：代码编辑区。
- **底部**：终端（Terminal），用来运行程序。
  - 如果没看到终端，按菜单 `终端 → 新建终端`，或快捷键 `` Ctrl + ` ``。

## 三、运行洛书（Losu）程序

平台已内置洛书解释器，命令是 `losu` 或 `QLosu`（两个一样）。

### 3.1 运行内置示例

洛书自带了几个量子算法示例，位于 `$LOSU_PATH` 目录里：

| 文件                   | 说明          |
| -------------------- | ----------- |
| `deutsch.losu`       | Deutsch 算法  |
| `grover.losu`        | Grover 搜索算法 |
| `superdense.losu`    | 超密编码        |
| `teleportation.losu` | 量子隐形传态      |
| `test.losu`          | 测试样例        |

在终端里运行（推荐用以下任一方式）：

```bash
# 方式一：用环境变量直接拼路径（最省事）
QLosu $LOSU_PATH/test.losu

# 方式二：先进入示例目录，再运行
cd $LOSU_PATH
QLosu test.losu

# 方式三：通过左侧文件夹里的软链接运行
QLosu losu-lpk-src/script/example/grover.losu
```

> ❗ **常见误区**：直接敲 `QLosu test.losu` 但当前目录没有这个文件时，会找不到文件、不会编译。
> 因为解释器只认你给的路径，**不会自动去 `$LOSU_PATH` 里搜索**。请按上面的方式带上正确路径。

运行成功后，终端会输出量子态（statevector）等结果，例如：

```
Qureg (2 qubit statevector, 4 qcomps, 168 bytes):
    0.5   |0⟩
    0.5   |1⟩
    -0.5  |2⟩
    -0.5  |3⟩
```

### 3.2 编写并运行自己的洛书程序

1. 在左侧资源管理器，右键你的工作区 → `新建文件`，命名为 `my.losu`。

2. 写入洛书代码并保存（`Ctrl + S`）。

3. 在终端运行：

   ```bash
   QLosu my.losu
   ```

> 编辑 `.losu` 文件时，已预装的**洛书插件**会自动提供语法高亮等支持。

### 3.3 想直接 `QLosu test.losu` 就能跑？

如果你觉得每次带路径麻烦，可以把内置示例**复制到自己的工作区**：

```bash
cp $LOSU_PATH/*.losu .
QLosu test.losu        # 这样当前目录就有文件了，可直接运行
```

## 四、常见问题（FAQ）

**Q1：页面打开报错 “WebSocket close 1006” / 无法连接？**
先**强制刷新**页面：`Ctrl + Shift + R`。若仍有问题，关掉标签页重新打开。

**Q2：我的文件还在吗？**

- 用户登录：文件保存在你的专属文件夹，下次登录还在。
- 游客登录：退出后即清空，不保存。

**Q3：忘记密码怎么办？**
密码无法找回。可以换一个新用户名重新登录（会创建新账号、新文件夹）。

**Q4：`QLosu test.losu` 提示找不到文件？**
当前目录没有该文件。请用 `QLosu $LOSU_PATH/test.losu`，或先 `cd $LOSU_PATH`。详见第三章。

**Q5：`losu-lpk-src` 里的文件能改吗？**
不能，它是只读的示例库。想修改请先 `cp` 复制到自己的工作区再编辑。

**Q6：怎么退出登录？**
浏览器访问 `http://43.143.217.79/_auth/logout` 即可退出。
