## 快速参考

### 基本语法

```losu
// 导入模块
var print import print

// 全局变量
var hello = "你好, "

// 函数定义 (使用 lambda 表达式定义)
var greet = { name =>
    return hello .. name .. "!"
}

// 局部变量
var message = greet("洛书用户")
print(message)
```

### 常用关键字

- **注释**: `//`, `/* */`
- **变量声明**: `var`
- **函数相关**: `return`, `yield`, `_`
- **流程控制**: `if`, `else if`, `else`, `while`, `for`, `in`, `break`, `continue`
- **逻辑运算**: `and`, `or`, `not`, `true`, `false`, `nil`
- **其他**: `import`, `...`

### 运算符

- **算术**: `+`, `-`, `*`, `/`, `%`, `**`, `/%`
- **比较**: `==`, `!=`, `<`, `<=`, `>`, `>=`
- **位运算**: `&`, `|`, `^`, `~`, `<<`, `>>`, `>>>`
**类型相关**: `->`, `->*`, `->?`, `->?*`, `->&String`, `->&Float`
- **特殊**: `..` (字符串拼接), `~>` (复合函数), `:>` (管道)
