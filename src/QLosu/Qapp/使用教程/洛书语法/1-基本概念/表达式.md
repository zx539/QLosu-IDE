# 表达式

表达式是洛书语言的核心组成部分，用于计算值和执行操作。洛书区分左表达式（L-value）和右表达式（R-value），这种区分对于理解赋值和引用机制非常重要。

## 表达式的基本概念

表达式是由操作数和运算符组成的计算单元，它们可以被求值并产生结果。洛书中的表达式具有丰富的类型和灵活的组合方式。

### 基本表达式类型

```losu
var print import print

// 字面量表达式
var number = 42
var text = "洛书语言"
var flag = true

// 变量表达式
var result = number

// 运算表达式
var sum = 10 + 20
var product = 5 * 6

print("字面量:" .. number->&String .. " " .. text .. " " .. flag->&String)
print("运算结果:" .. sum->&String .. " " .. product->&String)
```

## 左表达式（L-value）

左表达式是可以出现在赋值语句左边的表达式，它们表示内存中的存储位置，可以被赋值。

### 变量作为左表达式

```losu
var print import print

// 变量声明和赋值
var userName = "初始值"    // userName 是左表达式
var counter = 0           // counter 是左表达式

// 重新赋值
userName = "新用户名"     // userName 作为左表达式被赋值
counter = 10             // counter 作为左表达式被赋值

print("用户名:" .. userName)
print("计数器:" .. counter->&String)
```

### 对象属性作为左表达式

```losu
var print import print

// 创建对象
var user = {
    name: "张三",
    age: 25,
    email: "zhangsan@example.com"
}

// 对象属性作为左表达式
user.name = "李四"        // user.name 是左表达式
user.age = 30            // user.age 是左表达式

print("更新后的用户:" .. user.name .. user.age->&String)
```

### 数组元素作为左表达式

```losu
var print import print

// 创建数组
var numbers = [1, 2, 3, 4, 5]

// 数组元素作为左表达式
numbers[0] = 10          // numbers[0] 是左表达式
numbers[2] = 30          // numbers[2] 是左表达式

print("修改后的数组:")
for(var i=0,4 )
{
    print(numbers[i])
}
```

## 右表达式（R-value）

右表达式是产生值的表达式，它们可以出现在赋值语句的右边，但不能被直接赋值。

### 计算表达式作为右表达式

```losu
var print import print

var a = 10
var b = 20

// 算术表达式作为右表达式
var sum = a + b          // a + b 是右表达式
var difference = a - b   // a - b 是右表达式
var product = a * b      // a * b 是右表达式

print("计算结果:" .. sum->&String.. " " .. difference->&String.. " "  .. product->&String)
```

### 函数调用作为右表达式

```losu
var print import print

var getGreeting = { name =>
    return "你好, " .. name .. "!"
}

var userName = "洛书用户"

// 函数调用作为右表达式
var message = getGreeting(userName)  // getGreeting(userName) 是右表达式

print("问候消息:" .. message)
```

### 字面量作为右表达式

```losu
var print import print

// 各种字面量都是右表达式
var number = 42          // 42 是右表达式
var text = "洛书"        // "洛书" 是右表达式
var flag = true          // true 是右表达式
var array = [1, 2, 3]    // [1, 2, 3] 是右表达式

print("字面量值:" .. number->&String .. text .. flag->&String)
```

## 复合表达式

洛书支持复杂的表达式组合，可以构建功能强大的计算逻辑。

### 算术复合表达式

```losu
var print import print

var x = 5
var y = 3
var z = 2

// 复合算术表达式
var result1 = x + y * z        // 乘法优先级高于加法
var result2 = (x + y) * z      // 括号改变优先级
var result3 = x ** y + z       // 幂运算优先级最高

print("复合表达式结果:")
print("x + y * z =" .. result1->&String)      // 5 + 3 * 2 = 11
print("(x + y) * z =" .. result2->&String)    // (5 + 3) * 2 = 16
print("x ** y + z =" .. result3->&String)     // 5 ** 3 + 2 = 127
```

### 逻辑复合表达式

```losu
var print import print

var age = 25
var hasLicense = true
var hasExperience = false

// 复合逻辑表达式
var canDrive = age >= 18 and hasLicense
var isQualified = canDrive and (hasExperience or age >= 21)

print("驾驶资格检查:")
print("年龄:" .. age->&String)
print("有驾照:" .. hasLicense->&String)
print("有经验:" .. hasExperience->&String)
print("可以驾驶:" .. canDrive->&String)
print("完全合格:" .. isQualified->&String)
```

## 表达式的求值顺序

洛书遵循标准的运算符优先级和结合性规则。

### 运算符优先级

| 优先级 | 运算符 | 结合性 |
| :------: | :--------: | :------: |
| 9 | `**`, `-`, `not`, `~` | 右结合 |
| 8 | (无) | - |
| 7 | `*`, `/`, `/%`, `%`, `<<`, `>>`, `>>>` | 左结合 |
| 6 | `+`, `-` | 左结合 |
| 5 | `..`, `==`, `!=`, `<`, `<=`, `>`, `>=` | 左结合 |
| 4 | `&`, `^`, `and` | 左结合 |
| 3 | `\|`,`or` | 左结合 |
| 2 | `:>` | 左结合 |
| 1 | `~>` | 左结合 |

```losu
var print import print

// 演示运算符优先级
var a = 2
var b = 3
var c = 4

print("优先级演示:")
print("a + b * c =" .. (a + b * c)->&String)        // 2 + 3 * 4 = 14
print("a * b + c =" .. (a * b + c)->&String)        // 2 * 3 + 4 = 10
print("a ** b + c =" .. (a ** b + c)->&String)      // 2 ** 3 + 4 = 12
print("a + b ** c =" .. (a + b ** c)->&String)      // 2 + 3 ** 4 = 83
```

### 括号的使用

```losu
var print import print

var x = 10
var y = 5
var z = 2

// 使用括号明确求值顺序
var result1 = x / y + z      // 10 / 5 + 2 = 4
var result2 = x / (y + z)    // 10 / (5 + 2) = 1.43

print("括号的影响:")
print("x / y + z =" .. result1->&String)
print("x / (y + z) =", result2->&String)
```

## 特殊表达式

洛书提供了一些特殊的表达式形式，用于特定的操作场景。

```losu
var print import print

// 管道运算符 :>
var message = "洛书语言"
message :> print          // 等价于 print(message)

// 链式管道操作
var result = "Hello" :> print

// 复合运算符 ~>
var f = {x => x**2} ~> {x => x+1};
5 :> f :> print
```

### 练习 1：左右表达式区分

创建程序演示左表达式和右表达式的区别。

<summary>查看答案</summary>

```losu
var print import print

// 左表达式示例
var userName = "张三"        // userName 是左表达式
var userInfo = {
    name: "李四",
    age: 25
}

// 右表达式示例
var greeting = "你好, " .. userName    // "你好, " & userName 是右表达式
var sums = 10 + 20                    // 10 + 20 是右表达式

// 左表达式被赋值
userName = "王五"                    // userName 作为左表达式
userInfo.name = "赵六"               // userInfo.name 作为左表达式

print("=== 左右表达式演示 ===")
print("用户名:" .. userName)
print("用户信息:" .. userInfo.name .. userInfo.age->&String)
print("问候语:" .. greeting)
print("计算结果:" .. sums->&String)
```

### 练习 2：复合表达式计算

编写程序演示复杂表达式的计算和优先级。

<details>
<summary>查看答案</summary>

```losu
var print import print

var a = 4
var b = 3
var c = 2

print("=== 复合表达式计算 ===")
print("变量: a =" .. a->&String .. ", b =" .. b->&String .. ", c =" .. c->&String)

// 算术表达式优先级
print("a + b * c =" .. (a + b * c)->&String)        // 4 + 3 * 2 = 10
print("(a + b) * c =" .. ((a + b) * c)->&String)    // (4 + 3) * 2 = 14
print("a ** b - c =" .. (a ** b - c)->&String)      // 4 ** 3 - 2 = 62

// 逻辑表达式组合
var isValid = a > b and b > c
var isSpecial = a == 4 or b == 5

print("逻辑表达式:")
print("a > b and b > c = " .. isValid->&String)
print("a == 4 or b == 5 = " .. isSpecial->&String)
```
