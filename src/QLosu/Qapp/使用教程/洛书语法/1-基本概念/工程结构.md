# 工程结构

洛书语言采用基于模块（module）与包（package）的模块化设计，支持灵活的工程组织方式。本节详细介绍洛书的包运行机制和程序基本概念。

## 模块与项的概念

模块（module）是洛书语言的基本单位，其可以是一个洛书文件，也可以是一个C模块。本质上，一个模块是一个包含 `self` 指针的匿名函数，模块整体是该匿名函数的函数体。模块可以直接被导入。
一个模块由若干个 项（item）组成，项与项之间可以使用 `;` 分隔开。一个项可以是注释、变量、表达式与语句。

## 包的概念

包（package）是若干个模块的集合，并且每个包中都一定包含一个 `package.losu.json` 用于配置包信息。
包不能被直接导入，需要使用包管理器进行构建。

### 包的基本结构

原始结构：

```
std
|-math.losu
|-io.losu
|package.losu.json // 配置文件,必需
```

构建后结构：

```
std.math.losu
std.io.losu
std.losu
```

构建生成的包会被添加至 `$LOSU_PATH` 环境变量所指向的目录下。

## 导入模块

可以使用以下语法导入模块：

```losu
var 变量 import 模块
```

其中，“变量” 与 “模块” 符合洛书变量的语法规则，支持子成员、析构赋值等。

## 作用域

洛书的作用域分为全局作用域和局部作用域：

### 全局作用域

在模块最外层作用域声明的变量属于全局作用域：

```losu
var print import print

// 全局变量声明
var APP_VERSION = "1.0.0"
var DEBUG_MODE = "true"

// 全局变量可以在任何地方访问
print("版本:" .. APP_VERSION)
print("调试模式:" .. DEBUG_MODE)
```

### 局部作用域

在局部作用域中声明的变量属于局部作用域：

```losu
var print import print

var PrintLocalVar = { =>
    var localVar = "局部变量"
    print(localVar)
}

// 这里无法访问 localVar
```

### 作用域嵌套

洛书支持作用域的嵌套，内层作用域可以访问外层作用域的变量：

```losu
var print import print

var OUTER_VAR = "外层变量"

var middleFunction = { =>
    var middleVar = "中层变量"

    // 模拟内层作用域（通过函数）
    var innerFunction = { =>
        var innerVar = "内层变量"

        // 可以访问所有外层变量
        print("全局:" .. OUTER_VAR)
        print("中层:" .. middleVar)
        print("内层:" .. innerVar)
    }

    innerFunction()
}

middleFunction()
```

## 练习

### 练习 1：简单程序结构

创建一个简单的计算器程序，演示基本的程序结构。

<details>
<summary>查看答案</summary>

```losu
var print import print

// 简单的计算器程序
var num1 = 15
var num2 = 8

print("=== 简单计算器 ===")
print("数字1:" .. num1 ->&String) // ..: 字符串拼接, ->&String: 强制转换成字符串
print("数字2:" .. num2 ->&String)
print("加法:" .. (num1 + num2) ->&String)
print("减法:" .. (num1 - num2) ->&String)
print("乘法:" .. (num1 * num2) ->&String)
print("除法:" .. (num1 / num2) ->&String)
```

</details>

### 练习 2：使用全局变量与函数

创建一个程序，包含全局变量和函数定义。

<details>
<summary>查看答案</summary>

```losu
var print import print

// 全局配置
var PROGRAM_NAME = "洛书演示程序"
var VERSION = "1.0"

// 工具函数
var greetUser = { name =>
    return "欢迎使用洛书, " .. name .. "!"
}

print("=== 程序信息 ===")
print("程序名:" .. PROGRAM_NAME -> &String)
print("版本:" .. VERSION -> &String)

var userName = "开发者"
var greeting = greetUser(userName)
print(greeting)

print("程序运行完成")
```

</details>
