# 程序结构

洛书语言的程序结构清晰而灵活，支持全局和局部作用域的概念。本节详细介绍洛书程序的组织方式和作用域规则。

## 作用域概念

作用域（Scope）决定了变量和函数的可见性和生命周期。洛书支持两种主要的作用域：全局作用域和局部作用域。

### 全局作用域

全局作用域中的变量在整个程序中都可以访问。在模块最外层作用域声明的变量为全局变量。

```losu
var print import print

// 全局变量声明
var APP_NAME = "洛书应用程序"
var VERSION = "1.0.0"
var DEBUG_MODE = true

// 全局变量可以在程序的任何地方访问
var func = { =>
    print("应用名称:" .. APP_NAME)
    print("版本号:" .. VERSION)
    print("调试模式:" .. DEBUG_MODE->&String)
}

func()
```

### 全局变量的特点

1. **程序级可见性**：在整个程序中都可以访问
2. **生命周期长**：从声明开始直到程序结束
3. **命名约定**：建议使用大写字母和下划线

### 局部作用域

局部作用域中的变量只在特定的代码块中可见。在局部作用域中声明的变量为局部变量

```losu
var print import print

var func = { =>
    // 局部变量声明
    var userName = "张三"
    var userAge = 25
    var isActive = true

    print("用户信息:" .. userName .. userAge->&String .. isActive->&String)

    // 局部变量只在当前作用域内有效
}

// 这里无法访问 userName、userAge 和 isActive
func()
```

### 作用域嵌套

洛书支持作用域的嵌套，内层作用域可以访问外层作用域的变量：

```losu
var print import print

var GLOBAL_CONFIG = "全局配置"

var middleFunction = { =>
    var outerVar = "外层变量"

    var innerFunction = { =>
        var innerVar = "内层变量"

        // 内层可以访问所有外层变量
        print("全局变量:" .. GLOBAL_CONFIG)
        print("外层变量:" .. outerVar)
        print("内层变量:" .. innerVar)
    }

    innerFunction()

    // 这里无法访问 innerVar
    print("外层访问:" .. outerVar)
}

middleFunction()
```

## 变量声明和初始化

洛书提供了灵活的变量声明方式，支持不同的初始化模式。

### 基本声明语法

```losu
// 导入模块使用 import 关键字
var print import print

// 基本变量声明
var name = "洛书"

// 数组解构声明
var [count, message]
// 数组解构赋值
$[count, message] = [1, "Hello World"]
// 数组解构声明并赋值
var [count, message] = [1, "Hello World"]

// 对象解构声明
var { a,b,c }
// 对象解构赋值
${ a,b,c } = {
    "a": 1,
    "b": "Hello World",
    "c": true
}
// 对象解构声明并赋值
var { a,b,c } = {
    "a": 1,
    "b": "Hello World",
    "c": true
}
```

## 函数作用域

函数创建自己的局部作用域，函数参数和内部变量都属于函数的局部作用域：

```losu
var print import print

var MULTIPLIER = 2

var calculateValue= { input , factor =>
    // 函数参数 input 和 factor 是局部变量
    var localResult = input * factor * MULTIPLIER
    var tempValue = localResult + 10

    return tempValue
}

var result = calculateValue(5 , 3)
print("计算结果:" .. result->&String)

// 这里无法访问 localResult 和 tempValue
print("全局乘数:" .. MULTIPLIER->&String)
```

## 作用域最佳实践

### 变量命名约定

```losu
var print import print

// 全局常量：大写下划线
var MAX_RETRY_COUNT = 3
var DEFAULT_TIMEOUT = 30

// 全局变量：大写开头
var CurrentUser = "未登录"

var func = { =>
    // 局部变量：小写开头
    var userName = "张三"
    var userAge = 25

    // 私有变量：下划线开头
    var _internalState = "内部状态"

    // 临时变量：简短命名
    var temp = userName .. "_temp"

    print("用户:" .. userName .. "年龄:" .. userAge->&String)
    print("临时值:" .. temp->&String)
}

func()
```

### 作用域管理原则

1. **最小作用域原则**：变量应该在最小的必要作用域中声明
2. **避免全局污染**：尽量减少全局变量的使用
3. **清晰的命名**：使用有意义的变量名
4. **适当的生命周期**：变量的生命周期应该与其用途匹配

### 练习 1：简单计算器

编写一个简单的计算器，实现加法、乘法、平方功能。

```losu
var print import print

// 创建一个数学工具 Unit
var mathUtils = {
    add: {
        a , b => return a + b
    } ,
    multiply: {
        a , b => return a * b
    } ,
    square: {
        x => return x * x
    }
}

var func = { =>
    var num1 = 8
    var num2 = 3

    print("=== 数学工具演示 ===")
    print("数字:" .. num1->&String .. "和" .. num2->&String)
    print("加法:" .. mathUtils.add(num1 , num2)->&String)
    print("乘法:" .. mathUtils.multiply(num1 , num2)->&String)
    print("平方:" .. mathUtils.square(num1)->&String)
}

func()
```
