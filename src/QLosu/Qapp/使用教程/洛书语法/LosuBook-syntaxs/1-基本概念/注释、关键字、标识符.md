# 注释、关键字、标识符

本节介绍洛书语言的基础语法元素：注释的使用方法、关键字列表和标识符的命名规范。这些是编写洛书程序的基础知识。

## 注释语法

洛书使用 `//` 或 `/* */` 符号进行注释。注释是程序中不被执行的文本，用于解释代码的功能和逻辑。

### 单行注释

单行注释从 `//` 符号开始，直到行末结束

```losu
// 这是一个完整的单行注释
var print import print

print("Hello, World!")  // 这是行末注释

// 程序的主要功能
var result = 10 + 20      // 计算两个数的和
print("结果:" .. result -> &String)   // 输出计算结果
```

### 多行注释的实现

多行注释从 `/*` 开始，直到 `*/` 结束

```losu
var print import print

/* ===================================
 * 这是一个多行注释的示例
 * 作者：洛书开发者
 * 日期：2026年
 * ===================================
 */

print("多行注释演示")
```

> [!NOTE]
> 良好的注释习惯是编写可维护代码的重要组成部分。注释应该解释"为什么"而不仅仅是"是什么"。

## 关键字

洛书语言包含一系列保留的关键字，这些关键字具有特殊的语法意义，不能**直接**用作普通的标识符。

### 逻辑运算关键字

用于逻辑运算和布尔值表示：

- `and` - 逻辑与运算符
- `or` - 逻辑或运算符
- `not` - 逻辑非运算符
- `true` - 布尔真值
- `false` - 布尔假值
- `nil` - 空值

```losu
var print import print

var isActive = true
var isComplete = false

print("活跃且完成:" .. (isActive and isComplete) -> &String)  // nil
print("活跃且完成:" .. (isActive or isComplete) -> &String)   // 1
print("非活跃:" .. (not isActive) -> &String)                // nil
```

> [!IMPORTANT]
> 在洛书的类型系统中，空值（nil）被用于表示逻辑假值，所有非空值（包括 0 ）都被视为逻辑真值

### 变量声明关键字

`var`：声明变量
`$`：数组结构赋值

```losu
var print import print

// 全局变量声明
var [APP_NAME,VERSION]
// 数组结构赋值必须使用 $ 符号
$[APP_NAME,VERSION] = ["洛书应用","1.0"]

var func = { =>
    // 局部变量声明
    var userName = "张三"
    var userAge = 25

    print("应用:" .. APP_NAME)
    print("版本:" .. VERSION)
    print("用户:" .. userName .. "年龄:" .. userAge -> &String)
}

func()
```

### 函数相关关键字

用于函数定义和控制：

- `return` - 函数返回
- `yield` - 协程让步
- `_` - 通配符/自身引用

```losu
var print import print
var async import async

// lambda 表达式
var add = { a, b =>
    // 默认返回最后一项（item）
    a + b
}
print(add(1, 2))

// 无参数时可忽略 =>
var hello = {
    // return 语句
    return "Hello Losu!"
}
print(hello())

// 通配符 _
var fib = { n =>
    if (n <= 1) {
        return n
    }
    else {
        // 通配符/调用自身
        return _(n - 1) + _(n - 2)
    }
}
print(fib(10))

// yiled 语句
var task = {
  id, n =>
  async{ // async 函数的返回值是一个 Thread，洛书用户态线程
    for(var i = 1, n){
      // print 函数回自动让出当前线程的CPU控制权
      print("task "..id->&String..": "..i->&String)
    }
  }
}
for(var i = 1, 5){
  print("@created task "..i->&String..": "..task(i, 5)->&String)
}
```

### 流程控制关键字

用于程序流程控制：

- `if` - 条件判断
- `else if` - 条件分支
- `else` - 默认分支
- `while` - 循环
- `for` - 遍历循环
- `in` - 迭代器关键字
- `break` - 跳出循环
- `continue` - 继续下次循环

```losu
var print import print

// 条件判断
var x = 15
if (x > 20) {
    print("大于20")
} else if (x > 10) {
    print("大于10")
} else {
    print("小于等于10")
}

// while 循环
var i = 0
while (i < 3) {
    print("while:" .. i -> &String)
    i = i + 1
}

// for-in 遍历循环
var arr = [10, 20, 30]
for (var val in arr) {
    print("for-in:" .. val -> &String)
}

// break 和 continue
for (var j = 1, 5) {
    if (j == 3) {
        continue  // 跳过3
    }
    if (j == 5) {
        break     // 在5处停止
    }
    print("break/continue:" .. j -> &String)
}
```

### 其他重要关键字

- `import` - 模块导入
- `...` - 混合 Unit 与数组格式

```
var print import print

var a = {
    "name": "losu";
     1,2,3,4,5
    }

print(a.name)
print(a[0])
```

## 标识符命名规则

标识符是用来命名变量、函数、类等程序元素的名称。洛书的标识符命名规则既灵活又严格。

### 基本命名规则

1. **首字符限制**：必须是字母（a-z, A-Z）、下划线（_）或 Unicode 字符
2. **后续字符**：可以是字母、数字（0-9）、下划线或 Unicode 字符
3. **大小写敏感**：`name` 和 `Name` 是完全不同的标识符
4. **关键字限制**：不能直接使用关键字作为标识符

### 有效标识符示例

```losu
var print import print

// 基本英文标识符
var userName = "用户名"
var user_age = 25
var _privateData = "私有数据"
var counter1 = 0

// Unicode 标识符（支持中文）
var 姓名 = "张三"
var 年龄 = 30
var 用户ID = 12345

print("英文标识符:" .. userName .. user_age->&String)
print("中文标识符:" .. 姓名 .. 年龄->&String)
```

### 使用关键字作为标识符

当需要使用关键字作为标识符时，可以使用富标识符 ` `` ` 包裹：

```losu
var print import print

// 创建包含关键字的对象
var studentInfo = {
    class: "三年级",
    `for`: "学习编程"     // for 是关键字
}

// 访问时需要使用 `` 包裹
print("班级:" .. studentInfo.class)
print("目的:" .. studentInfo.`for`)
```

### 推荐的命名约定

虽然洛书支持多种命名风格，但建议遵循一致的约定：

```losu
var print import print

// 变量和函数：小驼峰或下划线风格
var userName = "张三"
var user_name = "李四"

// 常量：全大写下划线
var MAX_RETRY_COUNT = 3
var DEFAULT_TIMEOUT = 30

// 私有变量：下划线开头
var _internalState = "内部状态"

print("用户名:" .. userName)
print("最大重试次数:" .. MAX_RETRY_COUNT->&String)
print("内部状态:" .. _internalState)
```

## 运算符概览

洛书支持丰富的运算符，用于各种计算和操作：

### 算术运算符

- `+` 加法
- `-` 减法
- `*` 乘法
- `/` 除法
- `%` 取模
- `/%` 整除
- `**` 幂运算

### 位运算符

- `&` 按位与
- `|` 按位或
- `^` 按位异或
- `<<` 左移
- `>>` 右移
- `>>>` 无符号右移
- `~` 按位取反

> [!NOTE]
> 无符号右移符之外的位运算符均视作int32_t
> 无符号右移符视作uint32_t

### 比较运算符

- `==` 相等
- `!=` 不等
- `<` 小于
- `<=` 小于等于
- `>` 大于
- `>=` 大于等于

### 类型相关运算符

- `->` 断言数据原始类型
- `->*` 断言 Unit 数据的 `(Meta) 'type'` 属性
<br>
- `->?` 检查数据原始类型
- `->?*` 检查 Unit 数据的 `(Meta) 'type'` 属性
<br>
- `->&String` 强制转换成字符串
- `->&Float` 强制转换成浮点数

### 特殊运算符

- `..` 字符串拼接
- `:>` 管道运算符
- `~>` 复合函数

```losu
var print import print

// 算术运算演示
var a = 15
var b = 4
print("算术运算:" .. (a + b)->&String .. " "
    .. (a - b)->&String .. " " ..
    (a * b)->&String .. " " .. (a / b)->&String)

// 字符串拼接
var greeting = "你好" .. ", " .. "洛书!"
print("拼接结果:" .. greeting)

// 管道运算符
var result = "管道运算:洛书语言" :> print  // 等价于 print("洛书语言")

// 复合函数运算符

var func = { a, b => a + b} ~> { a => a * a}
print("复合函数:" .. func(1, 1)->&String)
```
