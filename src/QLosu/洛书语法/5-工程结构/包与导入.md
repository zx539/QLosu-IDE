# 包与导入

洛书语言提供了灵活的包管理和导入机制，支持内置包的全局导入和用户自定义包的局部导入。这种设计既保证了核心功能的便捷使用，又提供了模块化开发的灵活性。

## 导入机制概述

洛书支持两种导入方式：

1. **全局导入**：使用 `import` 关键字导入内置包
2. **局部导入**：使用 `std::!import()` 函数导入用户自定义包或外置包

> [!IMPORTANT]
> 全局导入只执行一次，局部导入支持多次导入，文件会使用最后导入的包。

## 全局导入

### 导入内置包

内置包导入后，是与洛书虚拟体一体的。

```losu
# 导入标准库
import std

# 导入操作系统相关功能
import os

main {
    println('标准库已导入')
    # 可以直接使用 std 库的功能
}
```

内置包有三种导入方式：

```losu
import std # 导入一个包，并创建全局变量与命名空间。其具有全局唯一性，即在多个文件导入时，只导入一次
import std as global # 导入一个包，仅创建全局变量
import std as namespace # 导入一个包，仅创建命名空间
```

> [!NOTE]
> 包在被导入后，可以被设置为 `false` ，随后可以再次导入包，以实现热更新机制。包被设置为 `false` 后，其命名空间不再可被访问。举如下的一个例子：
> ```losu
> import std
>
> std = false
>
> main {
>    println("Hello World!") # 此处会正常运行
>    async(true) {
>        for (i in 1, 3) {
>            std::println("Hello World!") # 此处会报错
>        }
>    }
> }
> ```

### 多个内置包导入

```losu
import std
import os
import math

main {
    println('多个内置包已导入')
    # 所有导入的包都可以直接使用
}
```

## 局部导入

### 导入用户自定义包

```losu
import std

main {
    # 导入用户自定义的数学包
    let math = std::!import('math')

    # 使用导入的包
    let result = math.add(10, 20)
    println('计算结果:', result)
}
```

### 导入外置包

洛书中导入外置包与导入自定义包语法相同，只需要将包名放在 `std::!import()` 中即可。需要注意的是，当外置包与内置包名相同时，内置包的优先级高于外置包。

## 包的结构

### 包目录结构

洛书的包以目录形式存在，入口点是 `main.losu` 文件：

```
mypackage/
├── main.losu      # 包的入口文件
├── utils.losu     # 其他模块文件
└── config.losu    # 配置文件
```

### 包的导出

包需要使用 `return{}` 在最外层导出内容：

```losu
# math/main.losu - 数学工具包
import std

# 私有函数
let _validate = {
    lambda a, b => return typeof(a) == 'number' and typeof(b) == 'number'
}

# 导出包的内容
return {
    name: '数学工具包',
    version: '1.0',

    add: {
        lambda a, b => {
            if (_validate(a, b)) {
                return a + b
            } else {
                return 0
            }
        }
    },

    multiply: {
        lambda a, b => {
            if (_validate(a, b)) {
                return a * b
            } else {
                return 0
            }
        }
    },

    getInfo: {
        lambda => return '这是' & math.name & ' v' & math.version
    }
}
```

## 使用导入的包

### 基本使用

```losu
import std

main {
    # 导入自定义包
    let myMath = std::!import('math')

    println('包信息:', myMath.getInfo())

    # 使用包的功能
    let sum = myMath.add(15, 25)
    let product = myMath.multiply(6, 7)

    println('加法结果:', sum)
    println('乘法结果:', product)
}
```

### 多次导入

```losu
import std

main {
    # 第一次导入
    let math1 = std::!import('math')
    println('第一次导入:', math1.name)

    # 第二次导入（会使用最新的包）
    let math2 = std::!import('math')
    println('第二次导入:', math2.name)

    # 两次导入的结果相同
    println('是否相同:', math1.name == math2.name)
}
```

## 包的命名空间

### 避免命名冲突

```losu
import std

main {
    # 导入不同的包，使用不同的变量名
    let stringUtils = std::!import('string-utils')
    let mathUtils = std::!import('math-utils')
    let fileUtils = std::!import('file-utils')

    # 使用时通过变量名区分
    let text = stringUtils.upper('hello')
    let number = mathUtils.square(5)

    println('文本处理:', text)
    println('数学计算:', number)
}
```

### 练习 1：创建工具包

创建一个简单的字符串工具包并使用它。

```losu
# 假设这是 string-tools/main.losu 文件的内容
import std

return {
    name: '字符串工具',
    version: '1.0',

    isEmpty: {
        lambda str => return str == '' or str == null
    },

    length: {
        lambda str => {
            if (typeof(str) == 'string') {
                return sizeof(str)
            } else {
                return 0
            }
        }
    },

    concat: {
        lambda str1, str2 => {
            if (typeof(str1) == 'string' and typeof(str2) == 'string') {
                return str1 & str2
            } else {
                return ''
            }
        }
    }
}

# 使用包的代码
import std

main {
    # 模拟导入（实际需要真实的包文件）
    let stringTools = {
        name: '字符串工具',
        isEmpty: { lambda str => return str == '' },
        length: { lambda str => return sizeof(str) },
        concat: { lambda str1, str2 => return str1 & str2 }
    }

    println('包名称:', stringTools.name)

    let text1 = 'Hello'
    let text2 = ' World'

    println('文本1长度:', stringTools.length(text1))
    println('文本1是否为空:', stringTools.isEmpty(text1))
    println('拼接结果:', stringTools.concat(text1, text2))
}
```

### 练习 2：多包协作

演示多个包之间的协作使用。

<details>
<summary>查看答案</summary>

```losu
import std

main {
    # 模拟多个工具包
    let mathTools = {
        add: { lambda a, b => return a + b },
        multiply: { lambda a, b => return a * b }
    }

    let formatTools = {
        formatNumber: { lambda num => return '数字: ' & str(num) },
        formatResult: { lambda operation, result => return operation & ' = ' & str(result) }
    }

    # 使用多个包协作
    let a = 10
    let b = 5

    let sum = mathTools.add(a, b)
    let product = mathTools.multiply(a, b)

    println(formatTools.formatResult('加法', sum))
    println(formatTools.formatResult('乘法', product))
    println(formatTools.formatNumber(sum))
    println(formatTools.formatNumber(product))
}
```

</details>
