# 洛书线程

洛书线程（losu thread）是洛书语言中的轻量级并发执行单元。洛书采用混合态线程模型，结合了用户态线程的轻量性和内核态线程的并行能力，为开发者提供了高效且易用的并发编程体验。

## 线程模型

洛书采用 1:M:N 混合线程模型：

1. **1个主入口**：程序从 main 函数开始执行
2. **M个洛书线程**：用户态的轻量级线程，支持协作式调度
3. **N个操作系统线程**：在需要时将洛书线程映射到OS线程上执行

> [!IMPORTANT]
> 洛书线程是协作式调度的，这意味着线程需要主动让出控制权，不会在临界区被强制抢占，从而简化了同步机制。

## 线程特点

### 轻量级
- 创建和切换开销小
- 内存占用少
- 支持大量并发线程

### 协作式调度
- 线程主动让出控制权
- 减少竞态条件
- 简化同步机制

### 内置同步
- 编译器自动处理变量访问同步
- 无需手动使用互斥锁
- 避免死锁和竞态条件

## 基本概念

### 线程状态
洛书线程有以下几种状态：

1. **就绪（READY）**：等待执行的线程
2. **运行（RUNNING）**：正在执行的线程
3. **挂起（YIELD）**：主动让出CPU的线程
4. **终止（END）**：执行完毕的线程

### 线程事件
线程让出时可以指定事件类型：

1. **none**：无特定事件，下个周期直接恢复
2. **await**：等待其他线程完成
3. **tick**：定时器事件
4. **callback**：回调事件

## 线程创建

使用 `async` 函数创建洛书线程：

```losu
import std

main {
    println('主线程开始')

    # 创建异步线程
    async(true) {
        println('异步线程执行')
        println('异步线程结束')
    }

    println('主线程结束')
}
```

## 线程标识

`async` 函数返回线程对象，可以用于后续操作：

```losu
import std

main {
    println('创建线程')

    let thread1 = async(true) {
        println('线程1执行')
    }

    let thread2 = async(true) {
        println('线程2执行')
    }

    println('线程对象:', thread1)
    println('线程对象:', thread2)
}
```

        println('线程A: 执行完毕')

        println('线程B: 执行完毕')
    }

    println('主线程: 所有线程已创建')
}

### 练习 2：线程计数

创建多个线程，每个线程执行简单的计数任务。

<details>
<summary>查看答案</summary>

```losu
import std

main {
    println('=== 线程计数演示 ===')

    async(true) {
        for (i in 1, 3) {
            println('线程1: 计数', i)
        }
    }

    async(true) {
        for (i in 1, 3) {
            println('线程2: 计数', i)
        }
    }

    println('主线程: 计数任务已分配')
}
```

</details>
