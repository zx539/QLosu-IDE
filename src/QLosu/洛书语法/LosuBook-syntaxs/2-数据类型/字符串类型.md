# 字符串类型

洛书语言的字符串类型 `String` 用于处理文本数据。洛书字符串支持 UTF-8 编码，提供了丰富的字符串操作功能，包括拼接、格式化、JSON 处理等。

## 字符串字面量

洛书支持多种字符串字面量的表示方法：

### 基本字符串

```losu
var print import print;

// 基本字符串字面量
var greeting = "Hello, World!";
var name = "洛书语言";
var empty = "";

print("问候语：" .. greeting);
print("语言名：" .. name);
print("空字符串：" .. empty);
```

### 转义字符

洛书字符串支持常见的转义字符：

```losu
var print import print;

// 转义字符示例
var newline = "第一行\n第二行";
var tab = "列 1\t列 2\t列 3";
var quote = "他说：\"你好！\"";
var backslash = "路径：C:\\Users\\Name";

print("换行符:");
print(newline);
print("制表符：" .. tab);
print("引号：" .. quote);
print("反斜杠：" .. backslash);
```

### 十六进制形式的字符串

使用 `#x` 可以创建十六进制形式的字符串：

```losu
var print import print;
var s = #x4C4F5355363636 // 十六进制形式的字符串
print(s);
```

### 多行字符串

使用 `#|` 可以创建多行字符串：

```losu
var print import print;

// 多行字符串示例
var multiLine =
#|这是多行字符串
#|\n 不会转义，直接显示
#|可以跨越多行
#|非常适合 JSON、SQL 等长文本;

var jsonString =
#|{
#|  "name": "洛书",
#|  "version": "1.0",
#|};

print("=== 多行字符串演示 ===");
print("多行字符串:");
print(multiLine);
print("JSON 字符串:");
print(jsonString);
```

## 字符串拼接

洛书使用 `..` 运算符进行字符串拼接：

### 基本拼接

```losu
var print import print;

// 字符串拼接
var firstName = "张";
var lastName = "三";
var fullName = firstName .. lastName;

print("姓：" .. firstName);
print("名：" .. lastName);
print("全名：" .. fullName);

// 多个字符串拼接
var greeting = "你好，" .. fullName .. "!";
print("问候：" .. greeting);
```

### 字符串与其他类型拼接

需要注意的是，字符串只能与字符串拼接，其他类型需要先转换：

```losu
var print import print;

// 类型转换和字符串拼接
var name = "洛书";
var version = 1;
var isStable = true;

// 需要显式转换
var info = name .. " 版本 " .. version->&String;
print("版本信息：" .. info);

// 使用字符串拼接输出多个值
print("详细信息：" .. name .. " 版本 " .. version->&String .. " 稳定版：" .. isStable->&String);
```

## 字符串格式化

使用拼接进行格式化

```losu
var print import print;

// 字符串格式化
var name = "张三";
var age = 25;
var city = "北京";

// 基本格式化
var profile = "姓名：" .. name .. ", 年龄：" .. age->&String .. ", 城市：" .. city;
print(profile);

// 多行格式化
var detailedProfile = "用户信息:\n"
                    .. "  姓名：" .. name .. "\n"
                    .. "  年龄：" .. age->&String .. "\n"
                    .. "  城市：" .. city;
print(detailedProfile);
```

> [!IMPORTANT]
> 洛书中字符串都用双引号表示，并且内部转义字符都支持 JSON 格式。

## 字符串比较

字符串支持各种比较操作：

```losu
var print import print;

// 字符串比较
var str1 = "apple";
var str2 = "banana";
var str3 = "apple";

print("=== 字符串比较 ===");
print("str1: " .. str1);
print("str2: " .. str2);
print("str3: " .. str3);

print("str1 == str2: " .. (str1 == str2)->&String);  // false
print("str1 == str3: " .. (str1 == str3)->&String);  // true
print("str1 != str2: " .. (str1 != str2)->&String);  // true
print("str1 < str2: " .. (str1 < str2)->&String);    // true (字典序)
print("str1 > str2: " .. (str1 > str2)->&String);    // false
```

var firstName = "李";

### 练习 2：字符串格式化

创建一个简单的信息格式化程序。

<details>
<summary>查看答案</summary>

```losu
var print import print;

// 商品信息
var productName = "洛书编程教程";
var originalPrice = 128.00;
var discountRate = 0.15;
var quantity = 3;

print("=== 购物清单 ===");

// 计算价格
var discountAmount = originalPrice * discountRate;
var finalPrice = originalPrice - discountAmount;
var totalAmount = finalPrice * quantity;

// 格式化输出
var itemInfo = "商品：" .. productName .. "\n"
             .. "原价：¥" .. originalPrice->&String .. "\n"
             .. "折扣：" .. (discountRate * 100)->&String .. "%\n"
             .. "现价：¥" .. finalPrice->&String .. "\n"
             .. "数量：" .. quantity->&String .. "\n"
             .. "总计：¥" .. totalAmount->&String;

print(itemInfo);

// 简单的收据格式
print("\n=== 收据 ===");
print("感谢购买 " .. productName);
print("您节省了 ¥" .. (discountAmount * quantity)->&String);
```

</details>
