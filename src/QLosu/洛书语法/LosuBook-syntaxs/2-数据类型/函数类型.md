# 函数类型

函数类型（function）是洛书语言中用于封装可执行代码的数据类型。洛书中函数定义全部使用lambda表达式。

## 函数的概念

洛书中的函数具有以下特点：

1. **一等公民**：函数可以作为值传递、存储和操作
2. **尾随参数**：支持unit类型的尾随参数语法糖
3. **运算方便**：支持管道运算与复合运算
4. **自动返回**：函数可以自动隐式返回最后一项（item），如果最后一项是空则返回 `nil`。也可以使用 `return` 显式返回。

## lambda 函数定义

洛书支持多种lambda表达式的写法，提供了灵活的函数定义方式：

### 含参数

```losu
var print import print;

var greet = {
  name =>
  print("Hello, " .. name)
};

// 函数调用
greet("洛书");
```

### 不含参数

```
var print import print;

var greet = { =>
    print("Hello, World!")
};

// 函数调用
greet();
```

### 不含参数，省略 `=>`

```
var print import print

var greet = {print("Hello, Losu!")}

greet()
```

## 函数作为值

洛书中函数是“一等公民”，可以作为值进行赋值或运算

```losu
var print import print;

// 函数定义
var multiply = {
  x, y =>
  x * y
};

// 函数可以赋值给变量
var operation = multiply

var result = operation(5, 6);
print("乘法结果：" .. result->&String);
```

## 函数通配符

如果需要在函数定义中调用自身，可以使用通配符 `_`。

```losu
var print import print;

var factorial = {
  n =>
  n <= 1
    and 1
    or n * _(n - 1)
};

print("10! = " .. factorial(10)->&String);
```

## 成员函数自调用

如果在调用成员函数时需要传递自身作为参数，可以使用 `!` ，例如 `f.g(f)` 便等同于 `f.g!()`。

```losu
var print import print;

var counter = {
  count: 0,

  increment: {
    self, step =>
    self.count = self.count + step
  },

  getCount: {
    self =>
    self.count
  }
};

// 自动传递 self
counter.increment!(10);
print(counter.getCount!()->&String);
```

## 管道运算符

管道运算符 `:>` 能够将左值作为参数传递给右值函数执行：

```losu
var print import print

var func = { i => i < 0 and -i or i };

// 等效于 print(func(-2))
-2 :> func :> print
```

## 复合运算符

复合运算符 `~>` 能够将左值函数作为参数传递给右值函数进行复合运算：

```losu
var print import print;

var f = {x => x ** 2}
var g = {x => x * 2}
// 等效于 h = g(f(x))
var h = f ~> g;

5 :> h :> print;
```

## 闭包

洛书中支持闭包，即函数内部可以引用外部变量，外部变量在函数内部被引用时，会自动被捕获，被捕获的变量与函数实例绑定。当出现同名变量时优先捕获最近作用域中的变量

```losu
var print import print;

var x = "outer";

var func = { =>
  var x = "inner";

  var PrintX = {
    print("x ：" .. x .. "\n")
  };

  PrintX()  // 调用内层函数
};


func();

var createCounter = {
  =>
  var count = 0;
  {
    =>
    count = count + 1;
    count
  }
};

var counterA = createCounter();
var counterB = createCounter();

print("计数器 A: " .. counterA()->&String .. ", " .. counterA()->&String .. ", " .. counterA()->&String);
print("计数器 B: " .. counterB()->&String .. ", " .. counterB()->&String);
```

## 立即表达式

洛书函数支持立即表达式语法，能够在定义函数后立即调用：

```losu
var print import print;

// 定义后立即调用
print("1 + 2 = " .. {a, b => a + b}(1, 2)->&String);

// 嵌套调用
print("嵌套：" .. {x => {y => y * 2}(x)}(5)->&String);
```

## 函数的语法糖

### 尾随参数语法糖

当函数的最后一个参数是unit类型时，可以使用尾随参数语法，将该参数放在函数调用的花括号中：

```losu
var print import print;

// 函数定义（使用 Lambda）
var processData = {
  name, config =>
  print("处理数据：" .. name);
  print("配置：" .. config.timeout->&String)
};

// 尾随参数语法：最后一个 Unit 类型参数可以尾随在 "()" 之后
processData("用户数据"){
  timeout: 5000
}
```

### 单参数unit函数的简化语法

```losu
var print import print;

// 函数定义
var configure = {
  settings =>
  print("应用配置：" .. settings->&String)
};

// 省略括号的写法（当只有一个 Unit 参数时）
configure {
  theme: "dark",
  language: "zh-CN"
};
```

这种语法糖使得配置类函数的调用更加简洁和直观，特别适合DSL（领域特定语言）的构建。

## 高阶函数

### 函数作为参数

```losu
var print import print;

// 高阶函数定义
var apply = {
  func, a, b =>
  func(a, b)
};

// 辅助函数定义
var add = {
  x, y =>
  x + y
};

var multiply = {
  x, y =>
  x * y
};

// 使用高阶函数
print("应用加法：" .. apply(add, 5, 3)->&String);
print("应用乘法：" .. apply(multiply, 5, 3)->&String);
```

### 函数作为返回值

```losu
var print import print;

// 高阶函数：返回函数的函数
var createMultiplier = {
  factor =>
  {
    x =>
    x * factor
  }
};

// 创建具体的倍数函数
var double = createMultiplier(2);  // 返回 { x => x * 2 }
var triple = createMultiplier(3);  // 返回 { x => x * 3 }

// 使用返回的函数
print("double(5) = " .. double(5)->&String);
print("triple(5) = " .. triple(5)->&String);
```

```losu
var print import print;

// === 1. 含参数的 Lambda 表达式 ===
var add = {
  a, b =>
  a + b
};

print("含参数的 Lambda：" .. add(10, 20)->&String);

// === 2. 不含参数的 Lambda 表达式 ===
var sayHello = {
  =>
  "Hello, Losu!"

print("不含参数的 Lambda：" .. sayHello());

// === 3. 省略箭头的 Lambda 表达式（单行可省略 =>）===

  3.14159
};

print("省略箭头的 Lambda：" .. getPi()->&String);
```

### 练习 2：函数语法糖和高阶函数

创建使用尾随参数语法糖的配置函数和高阶函数。

?> **练习要求**
实现一个配置处理函数，使用尾随参数语法糖，并创建一个高阶函数来处理数组。

<details>
<summary>点击查看答案</summary>

```losu
var print import print;

// === 使用尾随参数的配置函数 ===
var processConfig = {
  name, settings =>
  print("处理配置：" .. name);
  print("调试模式：" .. settings.debug->&String);
  print("端口：" .. settings.port->&String);
  print("主题：" .. settings.theme)
};

// === 单参数 Unit 函数 ===
var applySettings = {
  config =>
  print("应用设置:");
  print("  语言：" .. config.language);
  print("  区域：" .. config.region)
};

// === 高阶函数：接受函数作为参数 ===
var processArray = {
  arr, processor =>
  var i = 0;
  for (var item in arr) {
    processor(item, i);
    i = i + 1
  }
};

print("=== 函数语法糖演示 ===");

// === 使用尾随参数语法糖 ===
processConfig("应用配置"){
  debug: true,
  port: 3000,
  theme: "dark"
};

// === 单参数 Unit 函数省略括号 ===
applySettings {
  language: "zh-CN",
  region: "Asia/Shanghai"
};

// === 高阶函数使用 ===
var numbers = [1, 2, 3, 4, 5];

// 定义处理器函数
var numberPrinter = {
  item, index =>
  print("  处理数字 [" .. index->&String .. "]：" .. item->&String)
};

var stringPrinter = {
  item, index =>
  print("  处理字符串 [" .. index->&String .. "]：" .. item)
};

print("=== 高阶函数演示 ===");
processArray(numbers, numberPrinter);
processArray(["a", "b", "c"], stringPrinter);
```

</details>
