# 逻辑类型

洛书语言的逻辑类型包括 `true` 和 `false` 两个值。

## 逻辑值的类型

洛书的逻辑类型设计独特，`nil` 对应 `false` 值，而所有非 `nil` 值（包括0）都对应 `true` 值，`true` 值默认为 `Float` 类型的 `1`：

```losu
var print import print
var async import async

var False = false
var Nil = nil

var True = true
var Num = 3.14
var Str = "losu"
var Unit = {"a":"a"}
var Func = {=>"losu"}
var Thread = async {"losu"}
var Meta = 'Meta'

if(not False) {
    print(False)
}
if(not Nil) {
    print(Nil)
}

if(True->`Float`) {
    print(True) // True 在洛书中默认为 Float 类型的 1，并且洛书中实际上没有单独的 true 类型
}
if(Num) {
    print(Num)
}
if(Str) {
    print("Str")
}
if(Unit) {
    print("Unit")
}
if(Func) {
    print("Func")
}
if(Thread) {
    print("Thread")
}
if(Meta) {
    print("Meta")
}
```

## 逻辑运算符

洛书支持三种基本的逻辑运算符：`and`、`or` 和 `not`。

### 逻辑与 (and)

逻辑与运算符 `and` 只有当两个操作数都为真时才返回真：

```losu
var print import print

print("=== 逻辑与运算 ===")
print("true and true:" .. (true and true)->&String)      // true
print("true and false:" .. (true and false)->&String)    // false
print("false and true:" .. (false and true)->&String)    // false
print("false and false:" .. (false and false)->&String)  // false

// 实际应用示例
var age = 20
var hasLicense = true
var canDrive = age >= 18 and hasLicense

print("年龄:" .. age->&String .. " 有驾照:" .. hasLicense->&String)
print("可以开车:" .. canDrive->&String)
```

### 逻辑或 (or)

逻辑或运算符 `or` 只要有一个操作数为真就返回真：

```losu
var print import print

print("=== 逻辑或运算 ===")
print("true or true: " .. (true or true)->&String)        // true
print("true or false: " .. (true or false)->&String)      // true
print("false or true: " .. (false or true)->&String)      // true
print("false or false: " .. (false or false)->&String)    // nil (false)

// 实际应用示例
var isWeekend = false
var isHoliday = true
var canRest = isWeekend or isHoliday

print("是周末：" .. isWeekend->&String .. " 是假日：" .. isHoliday->&String)
print("可以休息：" .. canRest->&String)
```

### 逻辑非 (not)

逻辑非运算符 `not` 将真值变为假值，假值变为真值：

```losu
var print import print

print("=== 逻辑非运算 ===")
print("not true:" .. (not true)->&String)      // nil
print("not false:" .. (not false)->&String)    // 1

// 实际应用示例
var isLoggedIn = false
var needLogin = not isLoggedIn

print("已登录:" .. isLoggedIn->&String)
print("需要登录:" .. needLogin->&String)
```

## 短路求值

洛书的逻辑运算符支持短路求值，洛书使用 and 和 or 结合来进行短路求值：

```losu
var print import print

print("=== 短路求值演示 ===")

var a = 1
var b = 2
// c 取 a 和 b 之间的较小值
var c = (a > b) and b or a

print("c: " .. c->&String)  // 1
```

## 真值判断

在洛书中，以下值被视为假值，其他所有值都被视为真值：

- `false`
- `nil`

需要注意的是，`0`, `{}`, `[]`, `''` 和 `""` 等"空"值均被视为真值，因为洛书中一个变量一旦声明就不为 `nil` ，即使其没有值。

```losu
var print import print

print("=== 真值判断 ===")

// 测试各种值的真假性
var values = [true, false, nil, 1, 0, "hello", "", '', [1, 2], [], {}]

for (var value in values) {
    if (value) {
        print(value->&String .. "是真值")
    } else {
        print(value->&String .. "是假值")
    }
}
```

## 复合逻辑表达式

可以组合多个逻辑运算符创建复杂的条件：

```losu
var print import print

var age = 25
var hasLicense = true
var hasExperience = true
var hasRecommendation = false

// 复合逻辑条件
var isQualified = (age >= 18 and hasLicense) and (hasExperience or hasRecommendation)

print("=== 资格检查 ===")
print("年龄：" .. age->&String)
print("有驾照：" .. hasLicense->&String)
print("有经验：" .. hasExperience->&String)
print("有推荐：" .. hasRecommendation->&String)
print("符合资格：" .. isQualified->&String)
```

## 运算符优先级

逻辑运算符的优先级从高到低为：`not` > `and` > `or`

```losu
var print import print

print("=== 运算符优先级 ===")

// 演示运算符优先级
var result1 = true or false and false    // true or (false and false) = true
var result2 = not false or false         // (not false) or false = true
var result3 = true and false or true     // (true and false) or true = true

print("true or false and false = " .. result1->&String)
print("not false or false = " .. result2->&String)
print("true and false or true = " .. result3->&String)

// 使用括号改变优先级
var result4 = (true or false) and false  // (true or false) and false = false
print("(true or false) and false = " .. result4->&String)
```

### 练习 2：权限检查系统

使用逻辑类型实现一个简单的权限检查系统。

<details>
<summary>查看答案</summary>

```losu
var print import print

// 检查访问权限的函数
var checkAccess = {user =>
    // 检查用户是否存在
    if (not user) {
        return false
    }

    // 检查基本条件
    var isActive = user.active
    var hasRole = (user.role == "admin") or (user.role == "user")

    // 检查特殊权限
    var hasSpecialPermission = user.specialAccess

    // 综合判断
    return isActive and hasRole and ((user.role == "admin") or hasSpecialPermission)
}

// 测试用户数据
var users = [
    {"name": "Alice", "role": "admin", "active": true, "specialAccess": true},
    {"name": "Bob", "role": "user", "active": true, "specialAccess": true},
    {"name": "Charlie", "role": "user", "active": false, "specialAccess": true},
    {"name": "David", "role": "user", "active": true, "specialAccess": false}
]

print("=== 权限检查结果 ===")

for (var user in users) {
    var hasAccess = checkAccess(user)
    var status = hasAccess and "允许访问" or "拒绝访问"
    print(user.name .. ": " .. status)
}
```

</details>
