# Losu编程语言语法手册

欢迎使用Losu编程语言！这是一门现代化的动态类型编程语言，具有简洁的语法、强大的表达能力和丰富的特性。

## Hello, World

```losu
var print import print

print("Hello World!")
print("Hello Losu Language!")
```
