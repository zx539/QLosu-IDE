# 获取与安装

洛书（Losu）是一门现代化的动态类型编程语言，具有简洁的语法和强大的表达能力。本节将介绍如何获取和安装洛书开发环境。

## 获取方式

洛书提供了三种主要的获取方式，适合不同需求的用户：

### Playground 在线体验

洛书提供了功能完整的在线 Playground，这是最快速的体验方式：- **LosuOnline-Playground**：[在线playground地址](https://losu.tech/playground/)

- **即时体验**：无需安装，直接在浏览器中编写和运行洛书代码
- **实时反馈**：代码修改后立即看到运行结果
- **代码分享**：可以将代码片段分享给其他人
- **语法高亮**：完整的语法高亮和错误提示

> [!TIP]
> 对于初学者，建议先在 Playground 中熟悉语法，再考虑本地安装。

### Release 版本下载

从[官方发布页面](https://losu.tech/index-new/#download)可以下载预编译的洛书解释器：

- **稳定版本**：经过充分测试的稳定发布版本
- **多平台支持**：支持 Windows和Linux操作系统
- **绿色安装**：解压即用，无需复杂的安装过程

### SDK 开发工具包

完整的 [SDK](https://gitee.com/chen-chaochen/lpk) 适合需要深度开发的用户：

- **完整工具链**：包含解释器、编译器、调试器等全套工具
- **标准库源码**：可以查看和学习标准库的实现
- **开发文档**：详细的 API 文档和开发指南
- **示例项目**：丰富的示例代码和最佳实践

## 安装步骤

### Windows 系统安装

1. **下载解释器**：从官方页面下载 Windows 版本
2. **解压文件**：解压到合适的目录（如 `C:\losu`）
3. **配置环境**：将解释器目录添加到系统 PATH 环境变量
4. **验证安装**：打开命令提示符，运行 `losu --version`

### Linux 系统安装

1. **下载解释器**：选择对应系统架构的版本
2. **解压安装**：解压到 `/usr/local/bin` 或其他 PATH 目录
3. **设置权限**：运行 `chmod +x losu` 添加执行权限
4. **验证安装**：在终端运行 `losu --version` 确认安装成功

## 第一个程序

创建一个简单的洛书程序来验证安装：

```losu
var print import print

print("Hello, Losu!")
print("洛书安装成功！")
```

将代码保存为 `main.losu`，然后运行：

```bash
losu main.losu
```

如果看到正确的输出，说明洛书已经成功安装并可以正常使用。
