# 数值类型

洛书语言使用统一的 `Float` 类型来表示所有数值，包括整数和浮点数。这种设计简化了数值处理。

## 数值类型概述

洛书的数值类型具有以下特点：

1. **统一类型**：所有数值都是 `Float` 类型
2. **固定精度**：所有浮点数统一使用 double 类型表示
3. **自动转换**：整数和浮点数之间可以自动转换
4. **多进制支持**：支持十进制、十六进制、二进制字面量

### 基本数值字面量

```losu
var print import print;

// 整数字面量
var integer = 42;
var negative = -17;
var zero = 0;

// 浮点数字面量
var decimal = 3.14159;
var scientific = 1.23e-4;
var negativeFloat = -2.718;

print("整数:" .. integer->&String .. " " .. negative->&String .. " " .. zero->&String);
print("浮点数:" .. decimal->&String .. " " .. scientific->&String .. " " .. negativeFloat->&String);
```

### 多进制数值字面量

洛书支持多种进制的数值字面量，方便在不同场景下使用：

```losu
var print import print;

// 十进制（默认）
var decimal = 65;

// 十六进制（0x 前缀）
var hexadecimal = 0x41;

// 二进制（0b 前缀）
var binary = 0b1000001;

// ASCII 码形式（0a 前缀 + 字符）
var ascii = 0aA;  // 'A' 的 ASCII 码是 65

print("十进制：" .. decimal->&String);
print("十六进制：" .. hexadecimal->&String);
print("二进制：" .. binary->&String);
print("ASCII 码：" .. ascii->&String);

// 验证它们都表示相同的值
var allEqual = (decimal == hexadecimal)
               and (hexadecimal == binary)
               and (binary == ascii);
print("都等于 65:" .. allEqual->&String);
```

## 算术运算

洛书支持完整的算术运算符集合：

### 基本算术运算

```losu
var print import print;

// 基本算术运算
var a = 15;
var b = 4;

print("=== 基本算术运算 ===");
print("a = " .. a->&String .. ", b = " .. b->&String);
print("加法：a + b = " .. (a + b)->&String);       // 19
print("减法：a - b = " .. (a - b)->&String);       // 11
print("乘法：a * b = " .. (a * b)->&String);       // 60
print("除法：a / b = " .. (a / b)->&String);       // 3.75
print("取模：a % b = " .. (a % b)->&String);       // 3
print("幂运算：a ** b = " .. (a ** b)->&String);   // 50625
```

### 混合运算

整数和浮点数可以混合运算，结果类型根据操作数自动确定：

```losu
var print import print;

// 混合运算
var intValue = 10;
var floatValue = 3.5;

print("=== 混合运算 ===");
print("整数：" .. intValue->&String .. " 浮点数：" .. floatValue->&String);
print("整数 + 浮点数 = " .. (intValue + floatValue)->&String);    // 13.5
print("整数 * 浮点数 = " .. (intValue * floatValue)->&String);    // 35.0
print("整数 / 浮点数 = " .. (intValue / floatValue)->&String);    // 2.857...
```

## 数值比较

数值类型支持完整的比较运算：

```losu
var print import print;

// 数值比较
var x = 10;
var y = 20;
var z = 10.0;

print("=== 数值比较 ===");
print("x = " .. x->&String .. ", y = " .. y->&String .. ", z = " .. z->&String);
print("x == y: " .. (x == y)->&String);      // false
print("x == z: " .. (x == z)->&String);      // true (整数与浮点数比较)
print("x != y: " .. (x != y)->&String);      // true
print("x < y: " .. (x < y)->&String);        // true
print("x <= z: " .. (x <= z)->&String);      // true
print("y > x: " .. (y > x)->&String);        // true
print("y >= x: " .. (y >= x)->&String);      // true
```

## 数值转换

洛书提供了显式的数值转换函数：

```losu
var print import print;

// 字符串转数值
var strNumber = "123";
var strFloat = "3.14";

// 使用 ->&Float 将字符串转换为浮点数
var intFromStr = strNumber->&Float;
var floatFromStr = strFloat->&Float;

print("=== 数值转换 ===");
print("字符串转整数：" .. strNumber .. " -> " .. intFromStr->&String);
print("字符串转浮点数：" .. strFloat .. " -> " .. floatFromStr->&String);

// 数值转字符串
var numValue = 42;
var floatValue = 3.14159;

print("数值转字符串：" .. numValue->&String .. " -> " .. numValue->&String);
print("浮点数转字符串：" .. floatValue->&String .. " -> " .. floatValue->&String);
```

> [!WARNING]
> 洛书语言在数值运算中不允许将0作为除数，否则会报错。只有当 `/` 运算符被重载时，0才有可能被作为除数。

## 数值精度

在进行浮点数运算时需要注意精度问题：

```losu
var print import print;

// 浮点数精度示例
var a = 0.1;
var b = 0.2;
var sum = a + b;

print("=== 浮点数精度 ===");
print("0.1 + 0.2 = " .. sum->&String);
print("是否等于 0.3: " .. (sum == 0.3)->&String);

// 精度比较的正确方法
var epsilon = 1e-10;

// 使用 Lambda 实现 abs 函数
var abs = { x => x < 0 and -x or x };
var difference = abs(sum - 0.3);

print("差值：" .. difference->&String);
print("在精度范围内相等：" .. (difference < epsilon)->&String);
```

```losu
var print import print;

// 字符串转数值
var intStr = "123";
var floatStr = "3.14159";

// 使用 ->&Float 将字符串转换为浮点数
var intValue = intStr->&Float;
var floatValue = floatStr->&Float;
var hexValue = hexStr->&Float;

print("=== 数值转换演示 ===");
print("字符串转整数：" .. intStr .. " -> " .. intValue->&String);
print("字符串转浮点数：" .. floatStr .. " -> " .. floatValue->&String);
print("十六进制字符串：" .. hexStr .. " -> " .. hexValue->&String);

// 数值转字符串
var num = 42.5;
var numStr = num->&String;
print("数值转字符串：" .. num->&String .. " -> " .. numStr);

var a = 0.1;
var b = 0.2;
var sum = a + b;

print("=== 浮点数精度演示 ===");
print("0.1 + 0.2 = " .. sum->&String);
print("是否等于 0.3: " .. (sum == 0.3)->&String);

// 精度比较的正确方法
var epsilon = 1e-10;

// 使用 Lambda 实现 abs 函数
var abs = { x => x < 0 and -x or x };
var difference = abs(sum - 0.3);

print("与 0.3 的差值：" .. difference->&String);
print("在精度范围内相等：" .. (difference < epsilon)->&String);

// 数学运算（** 是内置运算符）
var base = 2;
var exponent = 8;
var power = base ** exponent;
print("幂运算：" .. base->&String .. " ** " .. exponent->&String .. " = " .. power->&String);
```
