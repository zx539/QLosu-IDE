## 语句概述

洛书的语句系统设计简洁而强大，支持现代编程语言的所有基本控制结构。

### 语句分类

1. **分支语句**：根据条件选择执行路径
   - `if` - 条件判断

2. **循环语句**：重复执行代码块
   - `while` - 条件循环
   - `for` - 遍历循环

3. **控制语句**：改变执行流程
   - `break` - 跳出循环
   - `continue` - 继续下次循环
   - `return` - 函数返回

### 语句语法特点

洛书的语句语法具有以下特点：

1. **条件表达式**：使用括号包围条件表达式
2. **代码块**：使用大括号定义代码块
3. **简洁语法**：避免冗余的关键字
4. **一致性**：所有语句遵循相似的语法模式

```losu
var print import print

var score = 85

// 分支语句示例
if (score >= 90) {
    print("优秀")
} else if (score >= 80) {
    print("良好")
} else {
    print("及格")
}

// 循环语句示例
for (var i = 1, 6) {
    print("计数:", i)
}

var numbers = [1, 2, 3, 4, 5]
for (var num in numbers) {
    print("数字:", num)
}
```

## 控制流程

### 顺序执行

默认情况下，语句按照编写顺序依次执行：

```losu
var print import print

print("第一步")
print("第二步")
print("第三步")
```

### 条件执行

使用分支语句根据条件选择执行路径：

```losu
var print import print

var weather = "晴天"

if (weather == "晴天") {
    print("适合出门")
} else {
    print("在家休息")
}
```

### 重复执行

使用循环语句重复执行代码：

```losu
var print import print

// 重复打印
for (var i = 1, 4) {
    print("重复执行第", i, "次")
}
```

## 语句嵌套

洛书支持语句的任意嵌套，可以构建复杂的控制逻辑：

```losu
var print import print

var students = [
    {name: "张三", score: 95},
    {name: "李四", score: 82},
    {name: "王五", score: 76}
]

print("=== 成绩评定 ===")

for (var student in students) {
    print("学生:" .. student.name)

    if (student.score >= 90) {
        print("等级: 优秀")
    } else if (student.score >= 80) {
        print("等级: 良好")
    } else {
        print("等级: 及格")
    }

    print("---")
}
```

## 最佳实践

### 代码可读性

1. **适当缩进**：保持一致的缩进风格
2. **清晰条件**：使用有意义的条件表达式
3. **避免深度嵌套**：过深的嵌套影响可读性

### 性能考虑

1. **循环优化**：避免在循环中进行重复计算
2. **条件顺序**：将最可能的条件放在前面
3. **提前退出**：使用 break 和 continue 优化循环

### 错误处理

1. **边界检查**：在访问数组或对象前检查边界
2. **空值检查**：处理可能为空的值
3. **异常情况**：为异常情况提供合适的处理

## 学习路径

建议按以下顺序学习语句：

1. **if 语句** - 掌握基本的条件控制
2. **while 循环** - 理解循环的基本概念
3. **for 循环** - 学习遍历和区间操作
4. **综合应用** - 结合多种语句解决实际问题

每种语句都有其适用场景，通过大量练习可以培养选择合适语句的直觉。
