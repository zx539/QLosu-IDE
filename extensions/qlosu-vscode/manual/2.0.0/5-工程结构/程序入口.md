# 程序入口

洛书语言提供了灵活的程序入口机制，支持简单的同步代码执行和复杂的异步程序结构。根据程序的复杂程度，开发者可以选择不同的入口方式。

## 入口方式概述

洛书支持两种主要的程序入口方式：

1. **直接执行**：适合简单程序，代码直接在文件中顺序执行
2. **main函数入口**：适合复杂程序，使用 `main{}` 作为程序入口点

> [!IMPORTANT]
> `main{}` 实际上是 `return{}` 的语法糖，只能有一个 main 块。

## 直接执行方式

### 简单程序

对于简单的程序，可以直接在文件中编写代码：

```losu
import std

# 直接执行的代码
let a = 10
let b = 20
let c = a + b

println('a =', a)
println('b =', b)
println('c =', c)
println('计算完成')
```

### 顺序执行

代码按照编写顺序依次执行：

```losu
import std

println('步骤1: 初始化')
let numbers = [1, 2, 3, 4, 5]

println('步骤2: 处理数据')
let sum = 0
for (num in numbers) {
    sum = sum + num
}

println('步骤3: 输出结果')
println('数组:', numbers)
println('总和:', sum)
println('平均值:', sum / sizeof(numbers))
```

## main函数入口

### 基本结构

对于复杂程序，建议使用 `main{}` 作为入口点：

```losu
import std

# 全局变量和函数定义
global let appName = '洛书应用'
global let version = '1.0'

let helper = {
    greet: {
        (name) {
        return '欢迎使用 ' , appName , ', ' , name
        }
    }
}

# 程序入口点
main {
    println('=== 应用启动 ===')
    println('应用名称:', appName)
    println('版本:', version)

    let userName = '用户'
    println(helper.greet('userName'))

    println('=== 应用结束 ===')
}
```

> [!IMPORTANT]
> 在洛书中，a.b(1)等价于 a::b(a,1)。即在上面的示例中，`helper.greet('userName')` 等价于 `helper::greet(helper, 'userName')`。要注意区分"::"和"."的使用情形

### 异步程序入口

main函数特别适合需要并发执行的复杂程序：

```losu
import std

global let taskCount = 0

main {
    println('=== 异步程序启动 ===')

    # 创建多个异步任务
    let task1 = async(true) {
        for (i in 1, 3) {
            taskCount = taskCount + 1
            println('任务1: 步骤', i, '总计数:', taskCount)
            yield
        }
        println('任务1: 完成')
    }

    let task2 = async(true) {
        for (i in 1, 3) {
            taskCount = taskCount + 1
            println('任务2: 步骤', i, '总计数:', taskCount)
            yield
        }
        println('任务2: 完成')
    }

    # 等待所有任务完成
    await(task1)
    await(task2)

    println('=== 所有任务完成 ===')
    println('最终计数:', taskCount)
}
```

### 包导出结构

当文件作为包被导入时，使用 `return{}` 导出：

```losu
import std

# 包的内部实现
let _privateData = {
    initialized: false,
    counter: 0
}

let _privateFunction = {
    lambda => {
        _privateData.counter = _privateData.counter + 1
        return _privateData.counter
    }
}

# 包的公共接口
return {
    name: '示例包',
    version: '1.0',

    initialize: {
        lambda => {
            if (not _privateData.initialized) {
                _privateData.initialized = true
                println('包已初始化')
            }
        }
    },

    getNextId: {
        lambda => return _privateFunction()
    },

    getStatus: {
        lambda => {
            return {
                initialized: _privateData.initialized,
                counter: _privateData.counter
            }
        }
    }
}
```

### 练习 2：任务管理系统

创建一个使用main入口的任务管理系统。

<details>
<summary>查看答案</summary>

```losu
import std

# 全局任务列表
global let tasks = []
global let taskIdCounter = 0

# 任务管理器
let taskManager = {
    createTask: {
        lambda name, priority => {
            taskIdCounter = taskIdCounter + 1
            let task = {
                id: taskIdCounter,
                name: name,
                priority: priority,
                status: 'pending'
            }
            tasks = tasks + [task]
            return task
        }
    },

    listTasks: {
        lambda => {
            println('=== 任务列表 ===')
            for (task in tasks) {
                println('ID:', task.id, '名称:', task.name, '优先级:', task.priority, '状态:', task.status)
            }
        }
    },

    completeTask: {
        lambda taskId => {
            for (task in tasks) {
                if (task.id == taskId) {
                    task.status = 'completed'
                    println('任务', taskId, '已完成')
                    return true
                }
            }
            println('未找到任务', taskId)
            return false
        }
    }
}

# 主程序入口
main {
    println('=== 任务管理系统启动 ===')

    # 创建一些任务
    taskManager.createTask('学习洛书语言', 'high')
    taskManager.createTask('编写文档', 'medium')
    taskManager.createTask('测试代码', 'high')

    # 显示任务列表
    taskManager.listTasks()

    # 完成一些任务
    taskManager.completeTask(1)
    taskManager.completeTask(3)

    println('=== 更新后的任务列表 ===')
    taskManager.listTasks()

    println('=== 系统关闭 ===')
}
```

</details>
