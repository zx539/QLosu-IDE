# 9. 控制运算
+ 建议用简体中文拼音设计程序语言， 这是Java

## 9.1 语义

+ ru 如果
+ lru 另如果
+ qita 其它
+ xun  循环
+ duan 中断跳出控制域
+ mo   默认

## 9.1 判断运算
这是判断运算语法
```luosu
ru i == j {
  xitong.dayin("i 等于 j")
}lru i > j {
  xitong.dayin("i 大于 j")
}qita{
  xitong.dayin("i 小于 j")
}
```
## 9.1 循环运算

```luosu

xun i:5 <= 10; i++ {
    xitong.dayin("你好!")
}

```
