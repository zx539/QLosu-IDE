# 0003 完整 Losu LSP 语言体验

- **优先级：** P0
- **状态：** 已完成（词典、悬浮文档和语义高亮增强；正式 Losu AST 仍可替换）
- **范围：** `language-server/losu-lsp/`

## 背景

当前 LSP 使用依赖零运行时的恢复式解析器，协议接口已经完整；正式 Losu AST 尚未在上游稳定，因此服务保留了可替换的解析边界。

## 待完成

- 接入 Losu 2.0 lexer/parser 或可复用的正式 AST。
- 实现语法和语义诊断、错误范围、错误码和源码映射。
- 实现上下文补全、悬停文档、跳转定义、查找引用、符号大纲。
- 实现安全的重命名、格式化、代码操作和语义高亮。
- 支持项目版本配置和文件级版本声明。
- 加入大文件、错误恢复、中文标识符和量子门 API 的测试。

## 验收标准

- VS Code 的 Problems、Completion、Hover、Go to Definition、Rename、Format Document 均可用。
- 语法错误不会导致 LSP 进程退出。
- 诊断行列与编辑器实际位置一致。
- 不同 Losu 版本不会错误复用另一版本的语法规则。

## 本次完成

- stdio LSP 支持初始化、增量文档同步和错误恢复，不因单个请求失败退出。
- 实现诊断（括号、控制流、版本声明）、上下文补全、悬停、定义、引用、符号大纲、重命名、格式化、代码操作、折叠范围和语义令牌。
- 支持中文标识符、量子门 API 词表、`qlosu.json` 项目版本以及文件头 `losu-version` 声明。
- 保持零运行时依赖，便于 Code-Server 和 Electron 随包启动。
- 根据 `lpk` vscode 语法定义补充控制流、标准库、数学库、WASM/UI API 和量子门词典；补全项带签名、分类、Markdown 文档和片段。
- 语法高亮覆盖字符串转义、数字字面量、声明、函数调用、运算符、量子 API 和语义令牌；悬浮提示显示签名、说明、分类与项目版本。

验证：`node --check server.js`、LSP initialize 握手和 `git diff --check` 通过。原生 Losu AST 接入仍可在后续版本替换内部 `parse` 函数，不影响协议接口。
