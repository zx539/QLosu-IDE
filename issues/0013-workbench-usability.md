# 0013 工作台路径、运行时、量子线路、终端与上次文件

- **状态：** 五项修复已完成，本机 Linux 浏览器交互验收通过
- **范围：** `extensions/qlosu-vscode/`、`runtime/`、`scripts/`、语法手册

## 问题与修复

1. 语法手册原先将 IDE 内部路径拼到任意工作区（例如 `examples/src/QLosu/洛书语法`），并且 Markdown 的换行处理不正确。现在扩展携带 1.0 / 2.0 离线手册，允许工作区相对路径和绝对路径覆盖；修复 23 个不存在的章节链接，并验证所有打包文档链接和图片。
2. 原先的版本选择只是文本输入，运行命令也没有使用所选版本。现在通过 API 检测并列出内置与外部运行时；工作台与 Agent 运行共同使用所选版本。从用户指定 Gitee lpk 源码编译了原生解释器、内核库及十个标准库模块，注册为 `losu-1.0`。上游自报版本仍保留在检测信息中。2.0 的脚本后端仍明确为 WASM。
3. 量子线路使用可直接阅读的 SVG：逐步从左向右排列，中文门说明、控制位/目标位图例、测量结果、寄存器选择和步骤点击说明；流程图保留 draw.io。
4. 终端缺少 `node-pty` 和 `native-watchdog` 原生构建产物，文件监听也发生崩溃。重建本机 Node ABI 的依赖，源码构建脚本也覆盖这些模块；新增 `code-server:repair` 与真实 PTY / 文件监听检查。
5. 工作台只读取 `activeTextEditor`，Webview 获取焦点后便无法运行。现在记住上次洛书文档并保存 URI，运行、图表和 Agent 共享文档选择；执行时读取当前文本。运行输出复用同一个输出通道。
